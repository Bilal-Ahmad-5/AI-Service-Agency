# 🚀 AI Services Agency

A multi-agent AI consultancy platform built with [Agency Swarm](https://github.com/VRSEN/agency-swarm?utm_source=chatgpt.com) and [Streamlit](https://streamlit.io?utm_source=chatgpt.com) that helps users analyze startup ideas and software projects using multiple AI experts.

The system simulates a real AI company with specialized agents like:

* 👨‍💼 CEO / Project Director
* 🏗️ CTO / Technical Architect
* 📦 Product Manager
* 💻 Lead Developer
* 🤝 Client Success Manager

Each agent collaborates to provide business, technical, and product recommendations.

# ⚙️ Installation

## Clone Repository

```bash id="xw7v4u"
git clone https://github.com/Bilal-Ahmad-5/AI-Service-Agency.git

```

## Create Virtual Environment

### Windows

```bash id="m9i9j5"
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash id="j2u6wv"
python3 -m venv venv
source venv/bin/activate
```

## Install Dependencies

```bash id="0r9b1l"
pip install -r requirements.txt
```

Then run:

### Mac/Linux


### Windows

